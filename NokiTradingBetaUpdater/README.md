# Noki Trading Beta

The beta is separate from the main Noki Trading release. Install the NokiTradingBeta folder in _forever_/Interface/AddOns, then enable Noki Trading Beta and disable Noki Trading on the character selection screen. The addons share runtime UI names and must not be enabled together. Beta settings and history use separate saved variables.

Run Noki Trading Beta Updater.exe, select your market, and update the data. It checks for addon updates under NokiTradingBeta in this repository and leaves the main addon untouched. Restart WoW or reload after updates. Market prices are supplied by AHledger.

The beta includes the 1.0.70 test features, the bag handle adjustment, and the incoming-auction-payment summary. Payment amounts are last-seen auction snapshots and may have arrived since the last check.
