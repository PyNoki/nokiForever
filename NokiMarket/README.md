# Noki Market

Vendor flip finder and auction lookup for World of Warcraft: Forever. Install this folder under `_forever_/Interface/AddOns/`, alongside Auctionator and AHledger. Run an auction scan and load current AHledger data with `/ahl import`, AHledger Sync, or the optional Noki Market Updater.

Estimated sales are market-wide, not confirmed trades. Listed quantities come from the latest scan. Gap / 1D compares estimated daily sales with listed units. No personal market snapshot is bundled; optional historical supply deltas need a separately sourced snapshot and do not update through AHledger's in-game API.

Prices from [AHledger](https://ahledger.com). Vendor observations are derived from [Efficient Games](https://efficient.games), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); vendor prices and availability can vary.
