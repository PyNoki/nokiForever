NOKI FOREVER UPDATER

Keep Update Noki Forever.bat somewhere convenient. Close WoW and run it whenever you want to install or update. It downloads the latest updater and addon from PyNoki/nokiForever on GitHub. Confirm the suggested Forever folder or select your World of Warcraft or _forever_ folder. Then start WoW.

The launcher downloads a fresh updater script every run. If the launcher itself ever needs changing, download a new copy from the repository. Windows may block writing to a protected game folder. The updater does not delete character settings.
