NOKI CRAFTING UPDATER

Requires Windows, Noki Crafting 1.0.3 or newer, and the AHledger addon.
1. Run Noki Crafting Updater.exe. Windows will ask for administrator access to update addons installed in Program Files.
2. Choose your region, ruleset, and faction. Select your NokiCrafting addon folder if needed.
3. Click Update now, then type /reload in game.
4. Optionally enable updates every 30 minutes while the app remains open. Reload the game to use each updated table.

The updater downloads market tables through devvy.xyz from AHledger. Prices from AHledger (ahledger.com). It does not upload your game data. It keeps separate tables for selected markets and will not replace a newer AHledger table. The app is unsigned; Windows may show a warning.
